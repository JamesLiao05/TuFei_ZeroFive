# 刷题宝典

一个跟「驾考宝典」差不多的刷题小页面：**顺序练习 / 随机练习 / 背题模式 / 模拟考试 / 错题本 / 收藏**，
支持左右滑动切题、单选多选判断自动判分、交卷计分、错题自动入库，手机和电脑都适配过。

纯静态，不需要后端，传到任何静态服务器（或直接双击本地文件）就能跑。

---

## 一、文件说明

| 文件 | 作用 | 要上传吗 |
| --- | --- | --- |
| `index.html` | 刷题页（题库切换入口，自动扫描题库文件夹） | ✅ 要 |
| `bank.js` | 内置题库数据（兜底用：本地双击打开或扫描失败时加载） | ✅ 要 |
| `admin.html` | 题库管理：导入、预览、导出 | ❌ 不要 |
| `题库/` | **题库来源文件夹**：题库 JSON、模板、图片（页面自动扫描） | ✅ 要（发布时一起传） |

`题库/` 文件夹内容：

| 文件 | 说明 |
| --- | --- |
| `题库/tiKu_dg3.json` | 电工三级（496 题） |
| `题库/tiKu_qzw.json` | 光电子技术·作业（112 题，含 2 张内嵌图） |
| `题库/tiKu_zl.json` | 屏蔽门系统·章节测验（83 题） |

| `题库/题库模板.json` | **给 AI 用的题库模板**（各种题型 + 图片写法） |

**题库文件夹就是题库的唯一来源**：页面打开时会自动扫描 `题库/` 里所有题库 JSON 并加载，往里放一个新题库 → 刷新页面即可识别，不需要改代码、不需要点导入按钮。`bank.js` 只是兜底（本地直接双击 `index.html` 打开、或服务器扫描失败时才用它）。

**发布时把整个文件夹一起上传**：`index.html` + `bank.js` + `题库/`（三者同一目录）。

## 二·补充：加新题库（放文件夹即可，自动识别）

### 办法 A：直接放 JSON 到题库文件夹（最省事，推荐）

1. 把新题库的 **JSON 文件**放进 `题库/` 文件夹（图片放 `题库/图片/` 子文件夹，或内嵌 base64，见办法 B）；
2. **刷新刷题页**，新题库自动出现在「📚 选择题库」列表里，点它切换，进度和其它题库互不干扰。

就是这么简单——页面会自动扫描文件夹，**没有导入按钮，也不需要手动选文件夹**。识别靠服务器列目录；绝大多数服务器都支持。万一你的服务器关闭了目录浏览，才需要把新文件名加进 `题库/_题库清单.json` 的 `files` 数组（一般不用管）。

> 每个题库的进度按题库 id 分开保存，切换后各自接着上次的记录。

### 办法 B：让 AI 用网页生成题库（含图片）

下次拿到新的学习通网页，想让别的 AI 帮你转成题库：

1. 把这三个东西一起发给 AI：
   - `题库/【给AI】生成题库说明.md`（任务要求）
   - `题库/题库模板.json`（格式模板）
   - 从学习通下载并保存好的网页 HTML（连同它旁边的 `xxx_files/` 图片文件夹一起压缩发）
2. AI 会按模板输出一个题库 JSON，**图片用相对路径**写，如 `"images": ["图片/电路图.png"]`；
3. 把 AI 生成的 JSON 和它提到的图片文件放进 `题库/`（图片放 `题库/图片/` 子文件夹，文件名要和 JSON 里写的一致）；
4. 刷新刷题页即可——页面会自动加载题库，并把相对路径图片转成正确地址显示出来。

图片也可以用完整的网络地址（http 开头）或直接内嵌的 base64，两种都支持。目前「光电子技术·作业题库」里那 2 道带图题就是用这种方式处理好的，可以作为样例参考。

## 三、怎么发布

1. 把 `index.html`、`bank.js` 和整个 `题库/` 文件夹上传到网站同一个目录（三者缺一不可，`题库/` 是题库来源）；
2. 打开 `你的域名/index.html` 就可以了（也可以把 index.html 设成默认首页）；
3. 以后要加题库，只要往服务器的 `题库/` 文件夹里放新 JSON，刷新页面即自动识别。

**换成自己的题 / 管理多套题库**：

1. 本地打开 `admin.html`（密码见下），顶部下拉选要编辑的题库；
2. 「导入题目」里选 JSON / 网页 HTML / 粘贴文本，先看预览；
3. 点「下载 bank.js」（会导出全部题库），用它覆盖网站上原来的 `bank.js`；
4. 刷新刷题页。如果还是旧题，`Ctrl + F5` 强制刷新（浏览器的缓存）。

刷题页首页顶部有「📚 选择题库」卡片，点进去可在多套题库间切换，每套题库的进度/错题/收藏各自独立。`index.html` 里没有题目，改题库不用动它。

## 四、管理页 admin.html

- 默认密码：`shuati2026`
- 改密码：用记事本打开 `admin.html`，在控制台（F12）执行 `__pwd('你的新密码')`，
  把它打印出来的哈希替换掉文件里的 `var PWD_HASH='152dan1';`
- 功能：**顶部下拉选择要编辑的题库**、查看统计、导入（JSON / HTML / 文本）、替换或合并去重、
  前 8 题预览、下载 `bank.js`（导出全部题库）、下载当前题库 JSON 备份、导出/导入本机学习进度
- 想新增一套题库：在下拉里选任一题库 → 用「替换」导入新题 → 下载 bank.js 覆盖。之后若要把新题库作为**独立的一套**（而不是替换现有），需手动在 `bank.js` 的 `window.BANKS` 数组里加一项并给它唯一的 `id`。

**注意**：这只是个前端密码，只能挡住随手点开的人，拿到文件的人绕过它很容易。
真要防止别人拿走题库，唯一靠得住的办法是把题目放到服务端、登录后才下发——那是下一步接后端时的事。

## 六、学习记录

- 每台设备（准确说是每个浏览器）各自存一份：进度、错题、收藏在 `localStorage` 的
  `shuati.bank.v1` 里，互不影响。
- 首次打开会生成一个**本机标识**，同时写进 cookie（`shuati_device`）和 localStorage，
  在「设置 → 本机标识」能看到。现在只用来区分设备，以后接后端时用它把记录对到具体设备。
- 想搬进度：在 `admin.html` 里「导出进度」，到新设备「导入进度」。

## 七、从学习通取题

前提：页面必须**已经显示出正确答案**（作业点「查看详情」后、章节测验点「查看答案」后、考完的试卷详情页）。

**方法 1：控制台脚本**（推荐）

1. 页面上按 `F12` → Console；
2. 把 `extract.js` 全部复制进去，回车；
3. 会打印题目表格并自动下载 `tiKu.json`，在 `admin.html` 里导入这个文件即可。

**方法 2：保存网页**：`Ctrl + S` 存成 html，在 `admin.html` 里「选择网页 HTML」。

**方法 3：直接复制**：`Ctrl + A` / `Ctrl + C`，在 `admin.html` 里「粘贴文本」。

文本格式大概这样（答案、解析可有可无，没答案不能判分）：

```
1.（单选题）中华人民共和国的首都是？
A. 上海
B. 北京
C. 广州
D. 深圳
正确答案：B
解析：北京是首都。
```

**批量**：`build_bank.py` 可以直接把一个保存好的网页转成题库文件，改开头的 `SRC` 路径即可。

## 八、题库 JSON 格式

```json
{
  "title": "计算机网络 期末复习",
  "questions": [
    { "type": "single", "stem": "题干", "options": [["A","甲"],["B","乙"]], "answer": ["B"], "analysis": "可省略" },
    { "type": "multi",  "stem": "多选", "options": [["A","甲"],["B","乙"],["C","丙"]], "answer": ["A","C"] },
    { "type": "judge",  "stem": "判断", "options": [["A","正确"],["B","错误"]], "answer": ["A"] },
    { "type": "fill",   "stem": "填空", "options": [], "answer": ["参考答案"] }
  ]
}
```

- `type`：`single` / `multi` / `judge` / `fill`（填空自己核对，不参与自动计分）
- `answer` 写选项字母，`["AC"]` 这种连写也能识别
- 判断题 `answer` 写 `"A"` 或 `"正确"` 都行
