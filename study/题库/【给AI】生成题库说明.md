# 用网页生成刷题题库（给 AI 的任务说明）

把这份文件和 `题库模板.json` 一起发给 AI，再加上从学习通下载并保存好的网页（HTML 文件），
让 AI 按下面的规则生成题库 JSON 文件。生成的文件放进本文件夹，打开刷题页点
「选择题库 → 导入题库文件夹」选中本文件夹即可使用。

---

## 你的任务

读取我提供的网页 HTML，把里面的题目（含选项、正确答案、必要的图片）转成下面格式的 JSON 文件。

## 输出格式

输出一个 JSON 文件，结构如下（也见 `题库模板.json`）：

```json
{
  "id": "",
  "title": "题库名称",
  "questions": [ /* 题目数组 */ ]
}
```

- `id` 留空字符串即可，程序会自动生成唯一 id。
- `title` 用网页的科目/作业名称，简短清楚。
- `questions` 是题目数组，每题字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `type` | ✅ | `single` 单选 / `multi` 多选 / `judge` 判断 / `fill` 填空 |
| `stem` | ✅ | 题干文字。去掉开头的「1.」序号和「（单选题）」这类题型标记（题型放 type 字段）。题干里的图片位置保留一句描述即可。 |
| `options` | ✅ | 选项二维数组 `[["A","选项一"],["B","选项二"]]`。判断题固定 `[["A","正确"],["B","错误"]]`；填空题写 `[]`。 |
| `answer` | ✅ | 正确答案字母数组，如 `["B"]`、多选 `["A","C"]`。判断题「对/正确」写 `["A"]`，「错/错误」写 `["B"]`。填空题直接写参考答案文字，如 `["参考答案"]`。 |
| `analysis` | 可选 | 解析文字，网页里有就带上，没有就省略这个字段。 |
| `images` | 可选 | 题目图片的文件名数组，如 `["图片/电路图.png"]`。见下方「图片处理」。 |

## 题型判断

- 网页里标「单选题 / 单选题」→ `single`
- 「多选题 / 不定项选择题」→ `multi`
- 「判断题」→ `judge`（即使网页没列出 A/B 选项，也要补上 `[["A","正确"],["B","错误"]]`）
- 「填空题 / 简答题」→ `fill`（options 写 `[]`，answer 里放参考答案文字）

## 答案提取

只提取网页里**已经显示出来的正确答案**（如 span.rightAnswerContent、「正确答案：X」等）。
如果网页里答案没显示出来，就不要编造，跳过该题。

## 图片处理（重要）

网页里题目如果带图（题干中有 `<img>` 标签）：

1. 把图片文件从网页旁边的 `xxx_files/` 目录里找出来，复制到本文件夹下的 `图片/` 子目录，起个简单好认的名字，例如 `电路图.png`、`光栅系统.png`。
2. 在对应题目的 `images` 字段里写下这个相对路径，例如 `"images": ["图片/电路图.png"]`。
3. 一道题多张图就写多个路径。
4. 如果图片是网络地址（http 开头），也可以直接填完整 URL。

> 刷题页在导入题库文件夹时，会把 `images` 里的相对路径图片自动转成内嵌图片，
> 所以图片文件必须和题库 JSON 一起放进文件夹，并且路径要写对（区分大小写）。

## 去重

按题干去重，题干完全相同的题只保留一道；如果两道题题干相同但答案不同，两道都保留并在 analysis 里注明。

## 输出要求

- 只输出一个 JSON 文件，文件名用题库名，例如 `计算机网络.json`，保存到本文件夹。
- 必须是合法 JSON（双引号、不能有多余逗号、不能有注释）。
- 生成后统计一下总题数和各题型数量告诉我。
